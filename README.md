# Smoak Paris

Site de commande & livraison Smoak Paris — plateforme façon Deliveroo / Uber Eats.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS

## Démarrer

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).
